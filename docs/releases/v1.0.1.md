# Nyrva v1.0.1 — CI hotfix and Codex integration fix

Patch release for the v1.0 line.

## Fixed

- Fixes the Rust type-inference error in the Codex native statusline integration that caused the main CI matrix to fail on Windows and Linux.
- Keeps the Codex integration resolution order explicit: `--home`, then `CODEX_HOME`, then the default `~/.codex`.
- Preserves the Windows CLI PATH and native Codex statusline changes included after the original v1.0.0 candidate.
- Aligns package, Tauri, lockfile, documentation and Codex app-server client version to 1.0.1.

## Distribution

The release workflow rebuilds and verifies the Windows NSIS installer, Debian package and AppImage from the exact tagged commit. The GitHub Release is created as a draft after all release gates pass.
